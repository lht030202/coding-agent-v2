# 项目教学文档

本套文档是"基于 Coding-Agent-SFT-Lab 二次开发的 Coding Agent"的学习材料，结构参照 Adaptive-RAG 项目的 tutorial。

全书按**技术主线**组织，共 **9 个部分**，按"打基础 → 会动手 → 管上下文 → 控风险 → 拿证据"五个阶段循序渐进。评测独立成部分，但不前置，放在技术讲完之后作为验证环节。

---

## 阅读方式

每个部分一个文件夹，内含一份 `00-说明.md` 作为导读（学习目标、练习与自测、代码位置），以及若干篇正文。

每篇正文的结构固定：

1. **开头一段**：交代本篇在第几部分、讲清什么、全文分几节。
2. **第一节"为什么"**：用一个具体场景引出问题。
3. **中间几节讲机制**，每节按"思路 → 真实代码（标注 `文件 —— 函数`）→ 代码解读 → 对照表 → 一句可直接复述的结论"展开。
4. **最后一节"反例与练习"**：一个"不这样设计会怎样"的反例、两道练习，以及"指标回指"（本篇服务于第八部分的哪个指标）。
5. **结尾**：本篇涉及的源码。

两组标记：

| 标记 | 含义 |
| --- | --- |
| ★ | 必须讲到代码级：面试官可能对着代码追问 |
| ○ | 讲到设计级：能说清思路和取舍即可 |
| 【原版】 | 仓库原有的实现 |
| 【改进】 | 你自己做的改动 |
| 【设计】 | 只有方案、没有实现：面试可以讨论，不能当成果 |

**原则：只写仓库里真实存在的行为；任何数字都带口径（模型 ID、任务数、运行次数、日期）。**

---

## 先记住这条任务链路

画架构图就靠它，所有面试回答都可以挂到这条链上：

```text
用户任务 + 仓库路径
  → index_repo    扫描仓库（文件树、符号表、关键词检索、文件预览），不调模型
  → plan          调模型写计划
  → act ⇄ verify  循环，最多 8 步
        act：拼 prompt → 调模型 → 解析出工具调用 → hooks 校验 → 执行工具 → 记录
        verify：调了 finish 或步数用完就结束，否则回到 act
  → review        换成"审查员" prompt 再调一次模型
  → summarize     写总结
  （每一步都写进 traces/*.jsonl）
```

代码入口：`run_agent.py` → `src/cc_agent/cli.py` → `src/cc_agent/graph.py`

## 源码阅读顺序

顺着一条任务走，而不是逐个文件翻：

1. **入口与配置**：`run_agent.py` → `cli.py` 的 `run` 命令 → `config.py` → `.env`
2. **模型调用**：`llm.py`
3. **图与状态**：`state.py` → `graph.py` 的 `build()`，在这里画出流程图
4. **按节点顺序**：`index_repo`（→ `repo_indexer.py`）→ `plan` → `act`（`_act_native` → `tools.py`、`hooks.py`、`context.py`；对照看 `_act_json` → `json_utils.py`）→ `verify`（`_verify_with_tests`）→ `review` → `summarize`
5. **轨迹与统计**：`tracing.py` → `trace_stats.py`
6. **评测**：`eval/task_defs.py` → `eval/build_tasks.py` → `evaluation.py`
7. **测试**：`tests/helpers.py`（假模型）→ `tests/test_graph.py`
