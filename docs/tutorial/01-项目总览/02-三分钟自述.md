# 三分钟自述

> **三分钟讲完一个完整项目。** 本文是一份约九百字的口播稿，按正常语速讲大约三分钟。

可以直接背，也可以按自己的语速微调，但建议保留五段结构和关键数字。

---

## 一、讲述原则

**其一，解决方案一段是重点。** 要讲清"为什么先做评测、评测发现了什么、所以改了什么"这条因果链，而不是罗列技术名词。

**其二，结果一段要带口径，并主动说明局限。** 带口径，数字才经得起追问；主动说局限，能提前化解面试官准备好的质疑。

---

## 二、口播稿

### 2.1 项目背景

我介绍一个代码仓库 Agent 项目。它的目标是：给一个代码仓库和一句任务描述，比如"金牌会员订单的税算错了"，Agent 自己去读代码、定位问题、修改文件、跑测试，最后审查并总结。

这个项目基于一个开源的 Coding Agent 二次开发。我保留了它用 LangGraph 编排的主流程，重做了工具调用、验证和评测这三块。

### 2.2 核心问题

原版有两个关键问题。

第一，工具调用靠在 prompt 里约定"只输出 JSON"，再用正则从回复里解析，格式一出错，任务就直接中止。

第二，它没有任务成功率这个指标。批量运行只能知道"程序没报错"，没法判断代码到底改对了没有。

### 2.3 解决方案

所以我先做评测，再做改进。

评测方面，我写了一个八个模块的小型电商代码库，往正确的代码里注入不同类型的 bug，每种 bug 就是一个任务。生成任务时自动校验两件事：用正确答案能做出来，修之前测试会失败。这个校验还查出了原数据集里的三道坏题。判定时，我先恢复原始测试，再加入 Agent 看不到的隐藏测试，防止它改测试或者只迎合能看到的测试。

跑原版基线时我发现，它失败的十五次全都是格式问题：请求里没带 tools 参数时，DeepSeek 会把自己原生的工具调用标记当成普通文本输出，原版的解析器找不到 JSON。

所以我把工具调用改成了原生 function calling：工具用 JSON Schema 描述，模型返回结构化的调用，执行结果用 tool 消息回传。参数写错、模型回复纯文本，都不再中止任务，而是作为观察结果交回模型。另外，我加了测试驱动验证：模型说完成之后，系统自动跑一遍测试，失败就把报错交回去继续修。

### 2.4 工程保障

工程上，我把模型调用收敛到一个入口：各家供应商的扩展参数（比如关闭 thinking）写在配置里，每次调用都记录 token 和耗时，失败会自动重试。

安全上，我修了原版命令白名单的几个漏洞，比如它允许 conda run，等于可以执行任意命令；运行测试之前，还会清除 API key 这类环境变量。

另外，我写了三十八个单元测试，用一个按剧本回复的假模型来测 Agent 的主循环，不调用真实接口。

### 2.5 结果与反思

在十二个任务、每个跑三次的评测里，成功率从百分之五十八点三提升到百分之九十七点二。其中多文件仓库任务从百分之三十七点五提升到百分之百，格式问题导致的中止从十五次降到零。按每个成功任务算，token 成本基本持平。

局限也很明确：任务集只有十二个，而且是我自己构建的；测试驱动验证在这批任务上没有被触发，所以我没有把它算进提升里。下一步是加上沙箱隔离，并在 SWE-bench 这类真实 issue 上做验证。

## 三、时长控制

| 段落 | 时长 | 任务 |
| --- | --- | --- |
| 项目背景 | 约二十五秒 | 说清 Agent 做什么、哪些是二次开发 |
| 核心问题 | 约二十秒 | 两个问题：格式中止、没有成功率 |
| 解决方案 | 约七十秒 | 先评测 → 发现 DSML → 改 function calling → 加测试验证 |
| 工程保障 | 约三十五秒 | 统一入口、安全修复、单元测试 |
| 结果与反思 | 约三十秒 | 三个数字加口径，主动说两点局限 |

时间紧张时，压缩背景和工程保障，不要压缩解决方案。

## 四、自查要点

- 总时长是否在三分钟左右，解决方案一段有没有被压缩。
- 有没有讲清因果链：是评测发现了 DSML 问题，才决定改协议。
- 数字后面有没有带"十二个任务、每个跑三次"这样的口径。
- 有没有主动说"基于开源项目二次开发"和"测试驱动验证没有被触发"。
- 模型名有没有说对：DeepSeek V4.1-Flash，通过硅基流动调用。

## 五、三十秒版本

> 我做了一个代码仓库 Agent，基于开源项目二次开发，用 LangGraph 编排，能自己读代码、改文件、跑测试。我先搭了评测，发现原版失败全是因为模型把自己的工具调用格式漏进了文本、导致解析中止，于是把工具调用改成原生 function calling。在十二个任务、每个跑三次的评测里，成功率从 58% 提升到 97%。
